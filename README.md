# Lemnova

Sistema de gestão para escritórios jurídicos, com controle de clientes,
processos, tarefas, financeiro e agenda.

🔗 Demo: https://jures-one.vercel.app

## Funcionalidades
- Dashboard com indicadores
- Cadastro de clientes e processos
- Controle financeiro e RPVs
- Agenda e tarefas
- Emissão de documentos

## Tecnologias
HTML5, CSS3, JavaScript (vanilla)

## Como rodar localmente
1. Clone o repositório
2. Abra o index.html no navegador (ou use um live server)
